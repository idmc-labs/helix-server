Retroactive Changes to GIDD Data

Downloadable Files (Excel):

All figures included in the downloadable files from the Global Internal Displacement Database (GIDD) have undergone rigorous expert validation to ensure alignment with IDMC’s data quality standards. Detailed documentation of the changes, including the analytical processes supporting them, is provided in the Tab 2_Context_Displacement_data of each file. A complete summary of historical figure revisions is also included in the accompanying README file.

API Access:

For users accessing GIDD data via the API, detailed documentation describing the methodology, caveats, and historical changes to figures is available through the public figure analysis endpoint: 

https://helix-tools-api.idmcdb.org/external-api/gidd/public-figure-analyses/?client_id=YOUR_API_KEY

This resource provides comprehensive information on the evolution of published figures over time.

Country-Level Historical Revisions:

A complete list of countries with historical data changes since 2025 is available in the following document:

GIDD_HistoricalChanges_13052025.xlsx
